# سایت شخصی آمنه سلحشور

سایت تک‌صفحه‌ای دوزبانه (فارسی / انگلیسی) — بدون فریم‌ورک، بدون build، فقط HTML و CSS و کمی جاوااسکریپت.

## محتویات پوشه

```
index.html          ← کل سایت در همین یک فایل است
assets/photo.jpg    ← عکس اصلی (هیرو)
assets/photo-2.jpg  ← عکس بخش «درباره من»
resume.pdf          ← فایلی که دکمه «دانلود رزومه» به آن لینک است
README.md           ← همین راهنما
```

## چطور چیزی را عوض کنم؟

`index.html` را با Notepad، VS Code یا هر ویرایشگر متنی باز کنید.

**متن‌ها دوزبانه‌اند.** هر عنصر دو صفت دارد:

```html
<h4 data-fa="متن فارسی" data-en="English text">متن فارسی</h4>
```

اگر متنی را عوض می‌کنید، هر سه جا را عوض کنید: `data-fa`، `data-en` و متن بین تگ‌ها.

**عوض کردن عکس:** فایل جدید را با همان نام `photo.jpg` در پوشه `assets` جایگزین کنید. (مربعی و حدود ۷۰۰×۷۰۰ پیکسل بهترین نتیجه را می‌دهد.)

**عوض کردن رنگ‌ها:** بالای فایل، داخل بلوک `:root` مقدار `--accent` و `--accent-2` را عوض کنید.

**اضافه کردن پروژه:** یکی از بلوک‌های `<div class="card proj rv">` را کپی کنید و محتوایش را عوض کنید.

## 📊 نمونه داشبوردها را کجا بگذارم؟

بخش **«گالری داشبورد»** برای همین ساخته شده است. با کلیک روی هر تصویر، در اندازه کامل باز می‌شود.

### قدم ۱ — تصویر را بگذارید

تصاویر را در پوشه‌ی زیر کپی کنید:

```
assets/dashboards/01.png
assets/dashboards/02.png
...
```

الان در این پوشه شش تصویر placeholder (جای‌خالی) هست. **هر کدام را با اسکرین‌شات واقعی خودتان جایگزین کنید** — همان نام فایل را نگه دارید تا نیازی به تغییر کد نباشد.

- فرمت: `png` یا `jpg`
- اندازه پیشنهادی: حدود ۱۶۰۰ در ۱۰۰۰ پیکسل (نسبت ۱۶:۱۰)
- حجم هر فایل زیر ۵۰۰ کیلوبایت باشد تا سایت سریع بماند

### قدم ۲ — عنوان و توضیح را عوض کنید

داخل `index.html`، پایین فایل، دنبال این بخش بگردید:

```js
var DASHBOARDS = [
  {
    img:     'assets/dashboards/01.png',
    titleFa: 'داشبورد مالی بیمارستان',
    titleEn: 'Hospital financial dashboard',
    descFa:  'درآمد به تفکیک بخش، پزشک و شرکت بیمه به همراه نرخ کسورات',
    descEn:  'Revenue by ward, physician and insurer, with deduction rate',
    tool:    'Power BI · SQL Server · SSAS'
  },
  ...
];
```

برای داشبورد جدید کافی است یکی از آیتم‌ها را کپی کنید و متن‌ها را عوض کنید. اگر تصویری موجود نباشد، آن کارت خودکار حذف می‌شود و چیزی خراب نمی‌شود.

### ⚠️ قبل از انتشار حتماً بخوانید

اسکرین‌شات داشبورد سازمان‌هایی که برایشان کار کرده‌اید **داده‌ی محرمانه** است. قبل از گذاشتن روی سایت عمومی:

1. **نام و لوگوی سازمان را حذف یا بلور کنید** — مگر اینکه اجازه کتبی داشته باشید.
2. **عددها را جایگزین کنید.** بهترین کار این است که همان داشبورد را با داده‌ی ساختگی (Sample/Dummy) دوباره رفرش کنید و از آن اسکرین‌شات بگیرید. ساختار و طراحی‌تان دیده می‌شود، عدد واقعی بیرون نمی‌رود.
3. **نام بیمار، پزشک، مشتری یا پرسنل نباید دیده شود** — به‌خصوص در داشبوردهای بیمارستانی که مشمول محرمانگی اطلاعات سلامت است.
4. اگر قرارداد محرمانگی (NDA) امضا کرده‌اید، حتی ساختار داشبورد هم ممکن است مشمول باشد — در آن صورت به‌جای اسکرین‌شات، یک **بازسازی** از همان داشبورد با داده‌ی نمونه بسازید و از آن استفاده کنید.

این شیوه کاملاً رایج و حرفه‌ای است؛ تقریباً همه‌ی پورتفولیوهای BI همین کار را می‌کنند.

### جایگزین‌های دیگر برای نمایش داشبورد

| روش | مناسب چه زمانی | نکته |
|---|---|---|
| **اسکرین‌شات در گالری سایت** (همین روش) | همیشه — ساده و مطمئن | کنترل کامل روی چیزی که دیده می‌شود |
| **Publish to web در Power BI** | وقتی داشبورد کاملاً با داده‌ی نمونه ساخته شده | لینک `iframe` می‌دهد و **کاملاً عمومی** است؛ هرگز با داده‌ی واقعی استفاده نکنید |
| **GIF کوتاه از تعامل با داشبورد** | وقتی می‌خواهید فیلترها و drill-down را نشان دهید | با ScreenToGif یا ShareX بگیرید |
| **نوشتن Case Study** | برای پروژه‌های بزرگ | «مسئله چه بود → چه ساختم → چه تغییری کرد» — حتی بدون تصویر هم قوی است |

پیشنهاد من: برای هر داشبورد یک اسکرین‌شات با داده‌ی نمونه + یک جمله که بگوید چه مشکلی را حل کرده است. همین کافی است.

## روش ۱ — انتشار رایگان روی GitHub Pages

آدرس نهایی: `https://USERNAME.github.io` — رایگان، همیشگی، با SSL.

### قدم به قدم

1. در [github.com](https://github.com) یک حساب بسازید. نام کاربری‌ای انتخاب کنید که دوست دارید در آدرس سایت دیده شود، مثلاً `ameneh-salahshoor`.

2. روی **+** بالا سمت راست → **New repository**.

3. در قسمت **Repository name** دقیقاً این را بنویسید:
   ```
   USERNAME.github.io
   ```
   یعنی نام کاربری خودتان + `.github.io`. مثلاً `ameneh-salahshoor.github.io`.
   نوع را **Public** بگذارید و **Create repository** را بزنید.

4. در صفحه‌ی مخزن روی **uploading an existing file** کلیک کنید.

5. محتویات این پوشه را بکشید و رها کنید: `index.html`، پوشه‌ی `assets`، و `resume.pdf`.
   ⚠️ خود پوشه‌ی بیرونی را آپلود نکنید — فایل‌های داخلش را آپلود کنید، طوری که `index.html` در ریشه‌ی مخزن باشد.

6. پایین صفحه **Commit changes** را بزنید.

7. ۱ تا ۳ دقیقه صبر کنید، بعد `https://USERNAME.github.io` را باز کنید. سایت بالا است.

> برای مخزنی با نام `USERNAME.github.io` لازم نیست کاری در تنظیمات انجام دهید؛ GitHub Pages خودکار فعال می‌شود. اگر اسم دیگری انتخاب کردید، باید به **Settings → Pages** بروید و در قسمت **Branch** گزینه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید. در آن حالت آدرس می‌شود `https://USERNAME.github.io/REPO-NAME`.

### به‌روزرسانی بعدی
فایل را در مخزن باز کنید → آیکون مداد → ویرایش → **Commit changes**. سایت ظرف چند ثانیه آپدیت می‌شود.

## روش ۲ — دامنه‌ی اختصاصی (پولی)

داشتن `amenehsalahshoor.com` به جای `username.github.io` برای رزومه ارزشش را دارد.

### الف) خرید دامنه

**دامنه‌ی بین‌المللی (`.com`، `.dev`، `.me`)**
- قیمت: حدود ۱۰ تا ۱۵ دلار در سال
- از داخل ایران معمولاً باید از ریسلرهای ایرانی خرید کنید (پارس‌پک، ایران‌سرور، میزبان‌فا، لیارا) چون پرداخت مستقیم به Namecheap/Cloudflare با کارت ایرانی کار نمی‌کند.

**دامنه‌ی `.ir`**
- قیمت: بسیار ارزان (حدود ۱۰ تا ۲۰ هزار تومان برای یک سال)
- از [ime.ir](https://www.nic.ir) (مرکز ثبت دامنه ایران) یا هر نمایندگی ایرانی
- نیاز به احراز هویت با کد ملی دارد

پیشنهاد: اگر دنبال کارفرمای داخلی هستید `.ir` کافی است؛ اگر دنبال موقعیت بین‌المللی یا ریموت هستید `.com` بهتر است.

### ب) وصل کردن دامنه به GitHub Pages

۱. در پنل دامنه‌تان به بخش **DNS** بروید.

۲. چهار رکورد `A` اضافه کنید (همه با نام `@`):
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

۳. یک رکورد `CNAME` اضافه کنید:
```
نام: www     مقدار: USERNAME.github.io
```

۴. در مخزن گیت‌هاب: **Settings → Pages → Custom domain** → دامنه‌تان را بنویسید و **Save** بزنید.

۵. تیک **Enforce HTTPS** را بزنید (ممکن است چند ساعت طول بکشد تا فعال شود).

۶. بین ۱۰ دقیقه تا ۲۴ ساعت طول می‌کشد تا DNS در همه‌جا پخش شود.

### هزینه‌ی کل
- هاست: **۰ تومان** (GitHub Pages رایگان است، حتی با دامنه‌ی اختصاصی)
- دامنه: فقط هزینه‌ی سالانه‌ی دامنه
- SSL/HTTPS: **رایگان** (GitHub خودش صادر می‌کند)

## چند نکته برای دیده‌شدن سایت

- آدرس سایت را در پروفایل لینکدین، در قسمت **Contact info → Website** بگذارید.
- در فایل `index.html` تگ‌های `<meta property="og:...">` تنظیم شده‌اند؛ وقتی لینک سایت را در لینکدین یا واتساپ بفرستید، عکس و توضیح درست نمایش داده می‌شود.
- اگر پروژه‌ای دارید که می‌توانید تصویرش را منتشر کنید (اسکرین‌شات داشبورد بدون داده‌ی محرمانه)، اضافه کردنش به بخش نمونه‌کارها تأثیر زیادی دارد.
- عددهای واقعی KPI (مثلاً «کاهش زمان تهیه گزارش ماهانه از ۳ روز به ۲ ساعت») قوی‌ترین چیزی است که می‌توانید اضافه کنید — هرجا عددی دارید که اجازه‌ی انتشارش را دارید، جایگزین توضیح کلی کنید.
